# 🏥 Jeevan Hospital Management System

A comprehensive, production-ready backend application developed using the latest technical features in the Spring ecosystem. This system is designed to streamline healthcare workflows, manage patient records, and optimize administrative efficiency.

## 🛠️ Tech Stack & Tools
*   **Language:** Java
*   **Framework:** Spring Boot, Spring Data JPA, Spring Security
*   **IDE:** Spring Tool Suite (STS)
*   **Database:** MySQL / PostgreSQL (with Hibernate ORM)
*   **Authentication:** JSON Web Tokens (JWT)


*   **Security & Auth:** Implemented modern stateless authentication using secure JWT mechanisms for role-based access control (Admin, Doctor, Patient, Staff).
*   **Core Logic:** Designed clean Repository and Service patterns utilizing Java Streams for optimal data filtering and performance.
*   **Database Management:** Configured detailed Hibernate mappings (One-to-Many, Many-to-One) and complex object relations to handle patient histories and appointment scheduling.
*   **RESTful APIs:** Secure and fully documented REST API endpoints for seamless frontend integration.
